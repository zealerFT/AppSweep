# AppSweep 中文操作手册

## 功能范围

| 功能 | 入口 | 结果 |
| --- | --- | --- |
| 应用扫描 | 左侧“应用”列表 | 列出支持目录中的已安装应用 |
| 清理优先级 | 应用列表上方排序菜单 | 按大小或最近使用时间查找清理对象 |
| 残留扫描 | 选择应用后自动执行 | 按 Bundle ID 列出关联文件 |
| 权限检查 | 工具栏“权限” | 打开系统设置并查看扫描提示 |
| 清理 | 详情页底部“移到废纸篓” | 将确认过的项目移到 macOS 废纸篓 |
| 操作记录 | 左侧“操作记录” | 查看每个项目的清理结果和废纸篓位置 |
| 完成提示 | 结果弹窗、工具栏“选项” | 关闭结果弹窗，或记住不再显示成功弹窗 |

## 安装应用

1. [下载 AppSweep-0.2.0-universal.dmg](https://github.com/zealerFT/AppSweep/releases/download/v0.2.0/AppSweep-0.2.0-universal.dmg)，要求 macOS 13 或更高版本，同一安装包包含 Apple Silicon 和 Intel 两种架构。
2. 双击打开磁盘映像，把 `AppSweep.app` 拖到“应用程序”文件夹。
3. 从“应用程序”文件夹打开 AppSweep。
4. 此预发布版尚未经过 Apple Developer ID 签名和公证。如果 macOS 提示无法验证开发者，请先确认下载来自本仓库，再打开“系统设置 → 隐私与安全性 → 仍要打开”，并确认“打开”。该按钮通常在尝试启动后才会出现；受组织管理的 Mac 可能不允许打开。

无需下载源码或自行编译。在 [版本下载页面](https://github.com/zealerFT/AppSweep/releases/tag/v0.2.0) 选择 `.dmg` 文件即可，`Source code (zip/tar.gz)` 是给开发者使用的源码。0.2.1 仍在修复和验证中，尚未发布。

## 授予完全磁盘访问权限

AppSweep 只在需要读取当前用户 Library 中受保护的目录时需要完全磁盘访问权限。

1. 在 AppSweep 工具栏点击“权限”。
2. 点击“打开系统设置”。
3. 打开“隐私与安全性 → 完全磁盘访问权限”。
4. 将 AppSweep 加入允许列表并打开开关。
5. 如果 macOS 要求重新打开应用，请按提示操作，然后在 AppSweep 点击“立即重新扫描”。

AppSweep 不会自动提权，也不会修改 SIP、Gatekeeper 或 macOS 的隐私设置。完全磁盘访问权限不等于管理员权限。

0.2.1 开发版在直接移动应用被拒绝时，会请求访达执行“移到废纸篓”。首次使用可能出现允许 AppSweep 操作访达的系统提示；需要管理员确认时也由系统处理。拒绝或取消会停止卸载并保留后续所选数据。权限面板不再提供“App 管理”入口，也不根据通用错误要求开启该权限。此流程仍待真实应用验收，尚未包含在已发布的 0.2.0 中。

更新临时签名版本后，旧授权可能不再匹配新版本。如果权限开关已开启却仍被系统拒绝，请退出 AppSweep，在对应权限列表移除旧条目，再添加“应用程序”中的当前 AppSweep，并重新打开。反复刷新不会改变系统授权。

选中应用本体时，先移除本体，再清理所选关联数据。本体被拒绝或用户取消时，关联数据保持原样。结果窗口直接显示失败说明，技术详情保留系统错误及错误代码；已移走的项目仍可从操作记录定位到废纸篓。

## 扫描应用

1. 在左侧列表选择应用。
2. 等待详情页显示“关联文件”。扫描期间可以点击取消按钮停止当前扫描。
3. 查看每一行的文件名、完整路径、类型和大小估算。
4. 使用详情页右侧的圆形箭头只重新扫描当前应用。
5. 使用右上角刷新按钮重新读取应用列表，并重新扫描当前选中的应用。

搜索框可以按应用名称或 Bundle ID 过滤结果。列表上方的排序菜单支持名称、应用标识、大小从大到小、大小从小到大、最久未使用优先、最近使用优先；关闭应用后仍会记住排序选择。

要找出优先考虑清理的应用：

1. 选择“大小从大到小”，查看占空间最大的应用；或选择“最久未使用优先”，查看长期未使用的应用。
2. 列表中的“应用大小”仅统计 `.app` 本体占用的磁盘空间，缓存等关联数据在选中应用后单独扫描。`>=` 表示统计尚不完整。
3. “最近使用”来自 macOS 的记录。“暂无记录”不等于从未使用，未知项始终排在有记录的应用之后。
4. 信息在后台读取时仍可搜索和选择应用；进度完成后排序结果更完整。需要更新信息时点击工具栏刷新。

## 选择要清理的内容

应用本体、缓存和日志默认选中。偏好设置、保存状态、应用支持目录、容器和网页数据默认不选中，因为其中可能包含账号、项目或已保存内容。

清理前请逐项检查路径：

- 确认路径确实属于当前应用；
- 对偏好设置、容器和应用支持目录，确认其中没有需要保留的个人数据；
- 如果同一个 Bundle ID 有多个安装副本，AppSweep 会保护共享数据；
- 如果应用正在运行，先点击“请求退出”，或手动退出应用。

可以点击“恢复默认选择”取消个人数据类项目的选择。

## 移到废纸篓

1. 检查选中数量和估算大小。
2. 点击“移到废纸篓”。
3. 在确认窗口再次查看清单。
4. 如果选择了个人数据，勾选确认框后才能继续。
5. 点击确认按钮，等待操作完成。

AppSweep 会在移动文件前重新检查应用运行状态、文件归属和文件身份。扫描后文件被替换或归属发生变化时，操作会停止并要求重新扫描。

文件会进入 macOS 废纸篓，清空废纸篓前不会立即释放磁盘空间。

## 关闭或取消完成提示

清理结束后，可以点击结果弹窗右上角的叉号、底部“关闭”，或按 Esc 关闭弹窗并继续查看应用列表。只有点击“查看记录”才会进入操作记录。

不想每次清理都弹窗时，勾选“成功清理后不再弹窗”后关闭。之后成功清理仅在列表底部显示简短结果，操作记录仍会正常保存，重新打开应用后选择依然有效。清理失败、只完成一部分或记录保存失败时仍会弹窗说明。

如需恢复成功弹窗，在工具栏点击齿轮“选项”，重新勾选“清理成功后显示弹窗”。

## 查看和恢复操作记录

1. 点击左侧“操作记录”。
2. 展开一条记录查看每个项目的原始路径、状态和错误信息。
3. 点击文件夹按钮在访达中定位废纸篓中的项目。
4. 如果需要恢复，请在清空废纸篓前通过访达将文件移回原位置；不要覆盖已经出现的新文件。

操作记录保存在当前 Mac，不会上传到网络。路径可能包含个人信息，请不要在公开截图中暴露。

## 扫描限制和扫描提示

### 扫描限制

“扫描限制”表示本次扫描可能遗漏内容，常见原因包括：

- 目录无法读取；
- 路径包含符号链接；
- 文件大小只能部分估算；
- 多个应用副本共用同一个 Bundle ID；
- 检测到登录项、后台服务、系统扩展或其它需要官方卸载器处理的组件。

只有权限或路径确实发生变化时才需要重新扫描。检测到后台服务、驱动、VPN 或安全软件时，请使用厂商提供的官方卸载程序。

### 扫描提示

“扫描提示”表示 AppSweep 发现了非标准或已经损坏的应用包，并已安全跳过。它不代表完全磁盘访问权限失效，也不要求用户反复授权，不会影响其它标准应用的扫描。

如果需要处理该应用，请使用应用自己的卸载器，或在访达中确认后移到废纸篓。不要为了清除提示而手动删除不确定的系统文件。

## 常见问题

### 授权后仍然显示限制

确认已经把当前正在运行的 AppSweep 加入完全磁盘访问权限，然后回到应用点击“立即重新扫描”。如果提示类型是“扫描提示”，它描述的是非标准应用包，不是权限问题，无需继续授权。

### 应用列表里找不到应用

当前版本扫描 `/Applications` 和 `~/Applications`。检查应用是否在这两个目录中，并确认它是标准的 `.app` 包。其它位置的应用可以先移动到“应用程序”文件夹，或者使用“选择应用...”尝试选择。

### 清理按钮不可用

确认扫描已经完成、至少选中了一个可清理项目，并且应用没有运行。受保护的 Apple 应用、共享数据和需要官方卸载器的组件不能通过 AppSweep 直接清理。

### 清理后磁盘空间没有变化

文件进入废纸篓后仍占用磁盘空间。确认操作记录无误后，再由用户自行清空废纸篓。

## 当前版本的边界

AppSweep 不清理钥匙串、共享 Group Containers、系统目录、其他用户目录、外置磁盘或无法确认归属的厂商目录。它也不会穷尽所有厂商自定义的安装方式，因此复杂套件、驱动、VPN 和安全软件应优先使用官方卸载程序。
