# AppSweep 0.2.0

## 中文

[下载 macOS 通用安装包](https://github.com/zealerFT/AppSweep/releases/download/v0.2.0/AppSweep-0.2.0-universal.dmg) · [操作手册](https://github.com/zealerFT/AppSweep/blob/v0.2.0/docs/USER_GUIDE.zh-CN.md)

- 新增按应用大小升序/降序、最久未使用/最近使用排序，并记住排序选择。
- 应用列表显示 `.app` 本体占用空间及 macOS 最近使用记录，信息在后台读取。暂无使用记录的应用排在最后，不会被误标成从未使用。
- 清理完成弹窗新增右上角叉号、“关闭”按钮和 Esc 关闭，不再强制进入记录。
- 勾选“成功清理后不再弹窗”可记住选择，成功后显示简短提示，操作记录仍会保存；工具栏“选项”可恢复弹窗。失败或未完成的清理仍会提示。

打开 `.dmg`，把 AppSweep 拖入“应用程序”替换旧版，保留一个副本即可。要求 macOS 13 及以上，包含 Apple Silicon 和 Intel 两种架构。无需下载源码或自行编译。

此版本仍是预发布版，使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。若 macOS 阻止首次打开，确认文件来自本仓库后，前往“系统设置 → 隐私与安全性 → 仍要打开”。应用不自动修改系统权限；更新后如 macOS 要求重新授权，请按系统提示操作。

## English

[Download the universal macOS installer](https://github.com/zealerFT/AppSweep/releases/download/v0.2.0/AppSweep-0.2.0-universal.dmg) · [README](https://github.com/zealerFT/AppSweep/blob/v0.2.0/README.md)

- Sort by app size in either direction, or by oldest/newest use. The chosen order is remembered.
- The list shows app-bundle disk usage and macOS last-use records, loaded in the background. Missing records stay at the end and are not treated as never used.
- Close the cleanup result using the X, Close button, or Escape without navigating to history.
- Remember the choice to suppress successful-cleanup dialogs. A non-modal notice replaces the dialog and history is still saved. Restore dialogs using Options in the toolbar. Failed or incomplete cleanups still show their result.

Open the `.dmg` and drag AppSweep to Applications, replacing the old copy. Requires macOS 13 or later and includes Apple Silicon and Intel binaries. No compilation is needed.

This is an ad-hoc-signed preview without Apple Developer ID signing or notarization. If macOS blocks the first launch, confirm the download came from this repository, then use System Settings → Privacy & Security → Open Anyway. Follow any macOS request to reauthorize access after updating.
