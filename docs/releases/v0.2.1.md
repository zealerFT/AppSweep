# AppSweep v0.2.1 — 卸载权限与失败恢复 / Removal Permissions

## 中文

- 使用 macOS 系统回收流程移除所选项目，允许系统显示自己的确认或认证界面。
- 先移除应用本体；被拒绝或用户取消时，保留尚未处理的关联数据。
- 失败结果直接显示下一步操作，并提供 App 管理、完全磁盘访问或访达入口。系统原始错误收纳在技术详情中。
- 清理期间应用被重新安装时停止关联数据处理；旧操作记录保持兼容。

安装：下载 `AppSweep-0.2.1-universal.dmg`，把 AppSweep 拖到“应用程序”并替换旧版。用户的操作记录和偏好设置会保留。

此预发布包仍为 ad-hoc 签名，尚未经过 Developer ID 签名和公证。更新后若系统拒绝访问，请退出 AppSweep，在对应权限列表重新添加当前应用，再重新打开；完全磁盘访问不等于管理员权限。AppSweep 不会绕过系统认证或安全设置。

验证：33 项核心检查；中英文各 28 项界面流程检查，含一次性测试目录的真实系统回收与恢复。权限失败界面已检查。尚未完成所有系统版本、Intel 实机及受管理设备的运行验收。

## English

- Use the macOS system recycle flow, allowing the system to display confirmation or authentication UI.
- Move the selected application first. Refusal or cancellation leaves subsequent associated data in place.
- Show actionable failure explanations with App Management, Full Disk Access and Finder links; retain raw errors in Technical Details.
- Stop associated-data removal if the app is reinstalled during cleanup. Existing history remains compatible.

Install `AppSweep-0.2.1-universal.dmg` and replace AppSweep in Applications. History and preferences are preserved.

This prerelease remains ad-hoc signed and is not Developer ID signed or notarized. If access is denied after updating, quit AppSweep, re-add the current app to the relevant permission list and relaunch. Full Disk Access does not grant administrator privileges. System authentication and protections are not bypassed.

Validation: 33 core checks and 28 native workflow checks in each language, including a real recycle-and-restore operation on a disposable fixture. Permission-failure layouts were inspected. Runtime coverage of all supported macOS versions, Intel hardware and managed devices remains incomplete.
