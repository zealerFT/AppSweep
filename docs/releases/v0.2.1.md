# AppSweep v0.2.1 — 未发布 / Unreleased

## 中文

- 直接回收应用被拒绝时，请求访达执行“移到废纸篓”，由系统处理自动化允许和必要的管理员确认。只对未被替换的应用重试；取消、数据项或其它错误不触发此流程。
- 先移除应用本体；被拒绝或用户取消时，保留尚未处理的关联数据。
- 删除权限面板的“App 管理”入口及卸载错误中的相关指引；访达拒绝和用户取消分别显示真实原因。
- 本地构建自动创建并复用私有的固定自签名身份，不需要付费开发者账号。更新会校验签名连续性，临时签名预览需显式开启；Developer ID 只用于可选的公证分发流程。
- 清理期间应用被重新安装时停止关联数据处理；旧操作记录保持兼容。

尚未发布安装包；公开下载链接仍指向已发布的 0.2.0 预览版。

已确认临时签名更新会使旧隐私授权失效，即使系统设置中的开关仍开启。固定签名身份可以在本地生成并复用，不要求购买开发者账号。从旧临时签名首次切换时，系统可能需要重新确认一次授权。实际应用卸载仍由用户验收，不将普通测试目录的回收成功视为该问题已修复。

本轮仅运行代码和构建检查，不自动操作系统设置、启动应用或卸载用户软件。尚未完成所有系统版本、Intel 实机及受管理设备的运行验收。

## English

- Ask Finder to move the app to Trash when direct recycling is denied, letting macOS handle Automation consent and any administrator confirmation. Retry only an unchanged application, never cancellation, data items or unrelated errors.
- Move the selected application first. Refusal or cancellation leaves subsequent associated data in place.
- Remove the App Management settings row and related removal-error guidance. Report Finder denial and user cancellation separately.
- Create and reuse a private self-signed identity for local builds without a paid Apple account. Check update identity continuity, and require explicit opt-in for ad-hoc previews. Developer ID is only needed for the optional notarized distribution flow.
- Stop associated-data removal if the app is reinstalled during cleanup. Existing history remains compatible.

No installer has been published for this version. Public download links still point to the published 0.2.0 preview.

Ad-hoc updates are confirmed to invalidate existing privacy grants even when their switches remain enabled. A persistent identity can be created and reused locally without purchasing an Apple account. The first switch from an ad-hoc build may require a one-time renewal of privacy grants. Actual app removal remains for user verification; recycling a disposable fixture does not establish that this case is fixed.

This pass runs code and build checks only, without operating System Settings, launching the app or uninstalling user software. Runtime coverage of all supported macOS versions, Intel hardware and managed devices remains incomplete.
