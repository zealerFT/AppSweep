# AppSweep 0.1.0

## 中文

首个可直接安装的预发布版，无需下载源码或自行编译。

1. 下载 **[AppSweep-0.1.0-universal.dmg](https://github.com/zealerFT/AppSweep/releases/download/v0.1.0/AppSweep-0.1.0-universal.dmg)**，适用于 macOS 13 及以上，内含 Apple Silicon 和 Intel 两种架构。
2. 双击打开，将 **AppSweep** 拖到 **Applications（应用程序）**。
3. 从“应用程序”文件夹打开 AppSweep。
4. 此预发布版使用 ad-hoc 签名，**尚未经过 Apple Developer ID 签名和公证**。如果 macOS 提示无法验证开发者，请在确认下载来自本仓库后，打开 **系统设置 → 隐私与安全性 → 仍要打开**，再确认“打开”。该按钮通常在尝试启动后才会出现；受组织管理的 Mac 可能不允许打开。
5. 需要扫描受保护的应用数据时，在 AppSweep 的“权限”中按指引授予完全磁盘访问权限；按 macOS 提示重新打开应用后，再点击“立即重新扫描”。

**下载 `.dmg` 即可；页面底部的 `Source code (zip/tar.gz)` 是开发者使用的源码。**

功能包括按 Bundle ID 查找关联文件、逐项确认后移到废纸篓、中文和英文界面，以及仅保存在本机的操作记录。

这是测试版：Intel 真机界面、最低系统版本和干净系统上的完整安装流程仍待验收。它不会处理所有厂商后台组件，也不承诺清除全部残留；需要专用卸载器的应用会提示使用官方卸载程序。

[中文操作手册](https://github.com/zealerFT/AppSweep/blob/v0.1.0/docs/USER_GUIDE.zh-CN.md) · [隐私说明](https://github.com/zealerFT/AppSweep/blob/v0.1.0/PRIVACY.md)

## English

The first installable preview. No compilation or developer tools are required.

1. Download **[AppSweep-0.1.0-universal.dmg](https://github.com/zealerFT/AppSweep/releases/download/v0.1.0/AppSweep-0.1.0-universal.dmg)** for macOS 13 or later. It includes Apple Silicon and Intel binaries.
2. Open the disk image and drag **AppSweep** to **Applications**.
3. Launch AppSweep from Applications.
4. This preview is ad-hoc signed and **does not have Apple Developer ID signing or notarization**. If macOS cannot verify the developer, first confirm that the download came from this repository, then choose **System Settings → Privacy & Security → Open Anyway** and confirm **Open**. This option normally appears after an attempted launch; managed Macs may prevent it.
5. Use **Permissions** in AppSweep to grant Full Disk Access when scanning protected application data. Relaunch if macOS requests it, then choose **Rescan now**.

**Choose the `.dmg` asset. The `Source code (zip/tar.gz)` downloads are for developers.**

Features include Bundle ID matching, review before moving files to Trash, Chinese and English interfaces, and local operation history.

This is a preview: Intel desktop use, the minimum macOS version, and the complete installation flow on a clean system still need validation. Vendor-specific components may need the vendor's official uninstaller; AppSweep does not promise to remove every trace.

## Build verification / 构建核对

The installer is built by GitHub Actions from the `v0.1.0` tag. `build-info.json` records the source commit, version, architectures, signing status, and installer SHA-256. The application also stores its source commit in `Info.plist` as `AppSweepSourceCommit`.

安装包由 GitHub Actions 从 `v0.1.0` 标签构建。`build-info.json` 记录源码提交、版本、架构、签名状态和安装包 SHA-256；应用的 `Info.plist` 也记录了源码提交。

To verify the download, place the `.dmg`, `build-info.json`, and `SHA256SUMS.txt` in the same folder and run / 如需校验，将三个附件放在同一文件夹，在该文件夹运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
